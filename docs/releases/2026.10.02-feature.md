# 2026.10.02-feature

**Date:** 2026-10-02 · **Kind:** feature · **Package version:** 0.1.0
(retrospective note, written when calendar versioning was introduced)

The first local pipeline: drop a long recording into a folder, run one command and
get a clean transcript, entirely on your own computer.

## Highlights

- **Qwen3-ASR on a local llama.cpp CUDA server**, with a forced spoken language
  and optional context or glossary to spell names and jargon correctly.
- **Pause-aware chunks.** Silero VAD on the CPU finds speech and cuts it at natural
  pauses into chunks of at most 15 seconds; silence never reaches the model.
- **Recovery ladder.** Looping or unusable answers are retried at other
  temperatures and, if needed, split; a chunk that still fails is reported as a gap
  and the job ends `incomplete` instead of stopping. Interrupted jobs resume.
- **Versioned, traceable outputs.** TXT, Markdown, SRT, VTT and JSON per input and
  per settings version, with `source.json`, `catalog.json`, a readable run report
  and an uncalibrated confidence score.
- **One command and a guided wizard** (`transcribe.cmd`) that also manages the
  model server; a single local configuration with pinned, checksum-verified
  downloads.
- **Live console and event stream.** Stages, chunk progress, ETA, speed and
  CPU/GPU sparklines on screen; `events.jsonl` and `status.json` for other tools.
- **License.** AGPL-3.0-only with a commercial licensing option.

## Fixes

- Long recordings no longer stop on a single looping chunk.
- Silence no longer produces invented sentences or prompt echoes.
- Fully processed files are archived despite millisecond rounding of the duration.

## Verification

A full two-hour recording, 581/581 chunks, in about 4–5 minutes on one desktop
NVIDIA GPU. See [verification](../verification.md#full-recording-with-qwen3-asr-2026-10-02).
