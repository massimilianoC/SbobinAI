# 2026.10.04-feature

**Date:** 2026-10-04 · **Kind:** feature · **Package version:** 0.1.0 at the time
(retrospective note, written when calendar versioning was introduced)

SbobinAI becomes easier to install, easier to use in your own language and usable
by AI agents and scripts, and it keeps working when CUDA is not available.

## Highlights

- **Automatic inference fallback CUDA → Vulkan → CPU.** If CUDA is not usable the
  run continues on Vulkan or on the CPU with a prominent warning; the backend,
  device and fallback are recorded in every report. `setup` installs the pinned
  Vulkan and CPU runtimes.
- **Agent-native command line.** Full `--help` for every command, `sbobinai man`,
  `--json` output with structured errors and stable exit codes, a `repl` shell, a
  generated [command-line reference](../cli-reference.md) and an agent manifest.
- **Wizard in six languages.** English, Italian, Spanish, French, German and
  Portuguese, chosen from the system language; numbered menus with examples; a
  spoken language can be given as a code or a name (`it`, `italiano`, `Italian`).
- **What happens to the original after success.** Keep everything (default), keep
  only a verified lossless FLAC of its audio, or delete it, after a complete
  transcription only.
- **Clearer project status.** A support-status table (verified, beta, untested,
  planned), a quick start that can be followed by an AI coding agent, and a
  [multiplatform analysis](../multiplatform-porting.md) with measured CUDA, Vulkan
  and CPU runs.

## Changes

- The wizard no longer asks for a transcript language: the transcript is always in
  the spoken language.

## Fixes

- A bounded run on a file shorter than the bound no longer archives the input.
- Language answers are normalised to ISO codes, so `italiano` and `it` are the same
  version.
- Brief Windows file locks no longer fail a job.
- The launchers no longer run twice from a command line containing `&&`, and no
  longer log false "fatal error" lines while the model loads.

## Verification

Vulkan and CPU runs on the same machine produced the same transcript as CUDA, about
2× and 9× slower. See [verification](../verification.md) and
[multiplatform porting](../multiplatform-porting.md).
