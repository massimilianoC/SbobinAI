# 2026.11.05-feature

**Date:** 2026-11-05 · **Kind:** feature · **Package version:** 0.1.0 at the time
(retrospective note, written when calendar versioning was introduced)

SbobinAI gains a guided desktop app and becomes a public alpha. Everything that
the command line does is now also available in a window: choose a recording,
trim it on a waveform, pick the outputs, follow the run and review the result
with subtitles.

## Highlights

- **Guided desktop app (Windows preview).** Five steps plus an optional sixth:
  recording (queue or import), language and context, interval and retention,
  recap and live progress with CPU, GPU, VRAM and RAM cards, results with
  per-section times and honest file checks, and review with live subtitles,
  a clickable waveform and a cue list. Start with `desktop.cmd` after installing
  the `desktop` extra. See the [desktop guide](../desktop.md).
- **Selectable outputs.** TXT, Markdown, SRT, VTT, transcript JSON, reports, MP3,
  FLAC and an optional 720p MP4 preview (`--output-formats`). The MP4 is encoded on
  the GPU with NVENC when available, otherwise on the CPU, with a visible warning.
  Changing formats never re-runs the model.
- **Interval selection.** `--start-seconds` with `--max-duration`, or the start/end
  handles in the app; an interval has its own job identity and always keeps the
  recording in the queue.
- **Safer retention in the app.** A copy imported through the picker may be deleted
  after full success (the original you picked is untouched); a file already in the
  queue defaults to keep.
- **Public alpha.** README hero image and screenshots from a real run (transcript
  text blurred), alpha status stated up front, an [installer plan](../installer-plan.md)
  (proposal), GitHub-only contacts and generic hardware descriptions.

## Changes

- The legacy Nexa backend was removed; the local llama.cpp server is the only real
  backend. A configuration with `backend = "nexa"` fails with a clear message and
  older configurations still load. Earlier versions and checkpoints stay valid.
- Internal planning notes left the public tree.

## Fixes

- Desktop steps 3 and 5 no longer scroll the page at the default window size.
- The results screen compares the result folder with a resolved output root.

## Verification

One 17-minute recording was transcribed through the real desktop window on CUDA,
with the NVENC MP4 preview and review playback; generated-audio checks drove every
screen. See [verification](../verification.md#real-recording-through-the-desktop-ui-2026-11-05).

## Known limits

The app was checked only with a model server that was already running; starting
it from the app could hang. This was fixed in [2026.11.16-critical](2026.11.16-critical.md).
